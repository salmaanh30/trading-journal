# Trading Journal

Log every trade and track net P&L, win rate, profit factor, average win/loss and your equity curve.

## Run it
Open `index.html` in a browser, or in VS Code right-click it → **Open with Live Server**.

## Notes
- Trades are saved in your browser (localStorage). Use **Export** to back them up as a JSON file, and **Import** to restore them (import replaces the current list).
- P&L = (exit − entry) × shares − fees for longs, and (entry − exit) × shares − fees for shorts.
